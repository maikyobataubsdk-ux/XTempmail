# XTempmail & Telegram Bot
![XTempmail preview](XTempmail.jpg)

## Introduction
XTempmail is a powerful tool to generate temporary emails and monitor inbox messages in real-time. It features both an interactive Terminal CLI and a **feature-packed Telegram Bot** with vibrant inline buttons, emoji status indicators, and custom premium styling!

## Installations
```bash
$ pkg update -y && pkg upgrade -y
$ apt update -y && apt upgrade -y
$ pkg install git
$ pkg install python -y
$ git clone https://github.com/Whomrx666/XTempmail.git
$ cd XTempmail
$ bash install.sh
```

---

## 🤖 Running Telegram Bot

To launch the Telegram Bot with colorful inline keyboard buttons:

1. Obtain a Bot Token from [@BotFather](https://t.me/BotFather) on Telegram.
2. Set your `BOT_TOKEN` environment variable and start the bot:

```bash
export BOT_TOKEN="your_telegram_bot_token_here"
python3 telegram_bot.py
```

### Bot Features
- **⚡ Instant Temporary Email**: Generate temporary emails instantly with 1-tap copy.
- **📩 Real-time Inline Inbox**: Check and read received emails directly inside Telegram.
- **🎨 Highly Advanced Inline Buttons**: Interactive multi-column UI with colorful emoji navigation.
- **👑 Telegram Custom / Premium Emojis**: Modern visual formatting for enhanced user experience.
- **📊 Usage Stats & Account Management**: Track generated emails and easily delete or refresh active sessions.
